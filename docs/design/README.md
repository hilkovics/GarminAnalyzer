# Dizajn „Kokpit“ (Claude Design)

Export z Claude Design, predloha pre Streamlit UI (fáza 7+) a React frontend (fáza 9).

- `kokpit.dc.html` + `support.js` – originálny export (otvor v prehliadači; potrebuje unpkg.com a Google Fonts).
- `screens/` – snímky sekcií vyrenderované 2026-10-23 (bez písiem Barlow a ikon – názvy ikon ako text sú chyba renderu, nie dizajnu).

Známe odchýlky vzorových dát od METRICS (neprenášať): váhy pripravenosti 35/30/20/15 % (správne 30/30/20/20 %), skóre formy 80 pri TSB −6,3 (správne 50 + 2·TSB), skrátené upozornenie pri zisteniach, tabuľka týždňa iba so „Spolu“, vymyslený dôvod tréningu.
